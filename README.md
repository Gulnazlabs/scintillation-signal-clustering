# Scintillation Signal Clustering

Репозиторий содержит решение задачи автоматической кластеризации сигналов, полученных со сцинтилляционного детектора.

## Описание задачи

Необходимо разделить 23 479 сигналов на три кластера:

- сигналы первого типа частиц;
- сигналы второго типа частиц;
- аномальные или неидентифицируемые сигналы.

Задача решалась методами машинного обучения без учителя.  
Качество решения оценивалось метрикой `accuracy`.

# Scintillation Signal Clustering

Репозиторий содержит решение задачи автоматической кластеризации сигналов, полученных со сцинтилляционного детектора.

## Описание задачи

Необходимо разделить 23 479 сигналов на три кластера:

- сигналы первого типа частиц;
- сигналы второго типа частиц;
- аномальные или слабо выраженные сигналы.

Задача решалась методами машинного обучения без учителя.  
Качество решения оценивалось метрикой `accuracy` на Kaggle.

## Структура репозитория

- `Signal_types_classification_Финальное_решение_new.ipynb` - основной ноутбук с финальным решением. Его нужно смотреть в первую очередь.
- `Signal_types_classification_экспериментальные_решения (1).ipynb` - экспериментальный ноутбук с первыми вариантами кластеризации.
- `Signal_types_classification_экспериментальные_решения(2).ipynb`- экспериментальный ноутбук с другими вариантами кластеризации.
- `Signal_types_classification_экспериментальные_решения_(3).ipynb` - дополнительные эксперименты и подбор финального rule-based решения.

## Финальное решение

В финальном решении используется rule-based PSD-подход.

Основная идея:

1. выполнить baseline correction и инверсию сигнала;
2. рассчитать признаки, описывающие форму импульса;
3. выделить несколько самых слабых сигналов в отдельный малый кластер;
4. остальные сигналы разделить на две группы по PSD-признаку `tail_to_total`;
5. перенумеровать кластеры под формат Kaggle.

Для расчёта признаков использовались окна:

- `145:165` — быстрая часть сигнала;
- `165:230` — хвостовая часть сигнала.

Лучший public score на Kaggle: `0.84032`.

## Эксперименты

В экспериментальных ноутбуках были протестированы:

- KMeans;
- IsolationForest + GMM;
- GMM на расширенном наборе признаков;
- GMM на PSD-признаках;
- rule-based PSD-подход с подбором параметров.

Лучший результат показал rule-based PSD-подход, так как он хорошо учитывает форму сигнала и отдельно обрабатывает слабые импульсы.
