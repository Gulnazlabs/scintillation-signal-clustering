# Scintillation Signal Clustering

Репозиторий содержит решение задачи автоматической кластеризации сигналов, полученных со сцинтилляционного детектора.

## Описание задачи

Необходимо разделить 23 479 сигналов на три кластера:

- сигналы первого типа частиц;
- сигналы второго типа частиц;
- аномальные или неидентифицируемые сигналы.

Задача решалась методами машинного обучения без учителя.  
Качество решения оценивалось метрикой `accuracy`.

## Структура репозитория

Финальное решение находится в ноутбуке:

`Signal_types_classification_Финальное_решение.ipynb`

В ноутбуке представлены:

- первичный анализ данных;
- визуализация исходных сигналов;
- коррекция baseline и инверсия сигналов;
- Feature Engineering;
- анализ PSD-признаков;
- обучение модели Gaussian Mixture Model;
- формирование итогового файла `submission_final.csv`.

## Итоговая модель

В качестве финальной модели использовалась `GaussianMixture` на PSD-признаках:

- `tail_to_total`;
- `tail_to_fast`;
- `integral_to_amplitude`.

Лучший публичный результат на Kaggle:

`0.69023`
